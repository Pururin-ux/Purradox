# Рисунки и референсы Purradox

Рисунки, которые видит ученик, лежат в [public/art](../source/frontend/public/art/). Для правки открой конкретную карточку и найди используемый файл в [карте уроков](../docs/textbook-visual-review.md) или в компоненте этой карточки.

- [Указатель мудборда](reference-index.json) хранит исходные имена и заметки о композиции, цвете и рисунке. Сами изображения находятся в локальной подборке пользователя. Папки `references` в старых манифестах ссылаются на неё.
- [Иллюстрации уроков](lesson-illustrations-20261113/manifest.json) связывают рабочие файлы с темами, исходниками и замечаниями по рисунку.
- [Мастер-файлы оптики](optics-20261118/manifest.json) и [слои для карточек](optics-20261118/fieldbook/manifest.json) лежат рядом с манифестами. Стекло, корпус и свет можно править по отдельности в Krita. Сверь положение приборов и лучей на рабочей странице после экспорта.
