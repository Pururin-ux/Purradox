# Скорость и плавность Purradox на мобильной ширине

Дата проверки — 17 ноября 2026. Chrome DevTools Local QA запущен из установленного пакета с Chrome DevTools MCP 1.13.0. В сравнении сборки отдавали одинаковый API и сжатые ресурсы на локальных адресах. Для трасс загрузки использовались 390 × 844 CSS px, DPR 2, замедление CPU ×4, Fast 4G и холодный кэш. Для движений и касаний использовались 320 и 390 px с тем же замедлением CPU и локальной сетью. Попытки выполнялись в пустых браузерных профилях.

## Загрузка

Главный файл JavaScript сократился с 199,63 до 161,41 КБ в gzip, главный файл CSS с 73,54 до 51,57 КБ. Код для окна продолжения и отчёта ЦТ загружается при входе в это состояние. Модели, лаборатории и часть стилей урока отделены от оболочки сайта. Каталог и сведения о вариантах ЦТ запрашиваются параллельно коду страницы. В учебнике браузер откладывает отрисовку далёких разделов, а все ссылки доступны для поиска и навигации.

Измерен LCP на 22 входах до и после правок. Для четырёх страниц дополнительно сделано по три пары с чередованием порядка. В таблице приведены медианы этих пар, где они были, и результаты первого сравнения для остальных строк.

Первый проход показал худшее время для урока и тренажёра о линзах и для профиля. В чередующихся замерах сам урок ускорился. В тренажёре по линзам и профиле разница укладывается в разброс. Общий проход Chrome DevTools на 390 px охватил 110 адресов без ошибок и горизонтального переполнения. В него вошли главная, каталоги, профиль, повторение, магазин, коллекция, 49 уроков, 49 подборок, демо и три полных варианта ЦТ.

## Движение и отклик

Карточка урока появляется без ожидания выхода предыдущей. Статичные деления и ползунки реже перерисовываются вместе с показаниями. Для траекторий двух шариков используются синхронные браузерные анимации. Высота меняется пропорционально квадрату времени, горизонтальное положение пропорционально времени. Текст показаний обновляется на измерительных отметках. Значения в конце опыта рассчитаны по той же модели.

| Сценарий | Ширина | До | После |
| --- | ---: | ---: | ---: |
| Полёт шариков, промежутки между кадрами дольше 34 мс | 390 px | 59 | 1 |
| Полёт шариков, промежутки между кадрами дольше 34 мс | 320 px | 52 | 2 |
| График скорости, 95-й процентиль промежутка между кадрами | 390 px | 20,9 мс | 7,1 мс |
| Лаборатория движения, 95-й процентиль промежутка между кадрами | 320 px | 27,8 мс | 7,1 мс |
| Следующая карточка, от касания до появления | 320 px | 812 мс | 348 мс |

Промежутки между кадрами получены через `requestAnimationFrame` за приблизительно 2,8 с. Отдельная трасса Chrome DevTools на итоговой сборке подтвердила полёт с p95 около 7 мс. Также проверены волна, столкновение, температура изотермы, время на графике самоиндукции и расстояние до предмета у линзы. В тренажёре вердикт и разбор отрисовываются отдельно. Время до полного разбора после проверки менялось от прогона к прогону. Устойчивое сокращение этого времени не установлено.

## Проверка поведения

- Сопоставлены размеры, цвет и положение элементов трёх уроков на 390 и 1280 px. Поиск, прокрутка до последней темы и возврат к результатам поиска проверены в самом каталоге.
- При обрыве загрузки кода лаборатории рабочая кнопка повторной попытки возвращает к сохранённой карточке.
- В Chromium и WebKit сверены координаты шариков во время движения, сброс при смене скорости и конечное положение. При 4 м/с сдвиг составил 2,00 м. Оба шарика коснулись пола через 0,50 с.
- Демо ЦТ прошло восстановление места и ответа после перезагрузки, продолжение таймера, сдачу и раскрытие разбора в Chromium, Firefox и WebKit.
- Локальная версия открывается на порту 4184. Измерения эмулируют мобильный экран и нагрузку в браузере на Windows. Производительность на физическом телефоне и на опубликованном сайте не измерялась.
