# Запуск локальной версии

Для ветки `codex/purradox-repair` рабочая папка находится в `C:\Users\lalad\.codex\worktrees\purradox-repair\physicslab-emergent`.

Открой [Purradox](http://127.0.0.1:4184/). После перезагрузки Windows запусти из корня этой рабочей папки команду ниже.

```powershell
.\start-local.cmd
```

Команда использует установленные Node.js, Python и зависимости проекта. Она проверяет API на порту 4183 и сайт на порту 4184, затем запускает нужные сервисы. При запуске в терминале держи его открытым. Ctrl+C останавливает сервисы, запущенные этой командой. [Установка зависимостей](source/README.md)

API, запущенный этой командой, подхватывает изменения файлов Python в `source/backend`. Если на 4183 уже отвечает процесс, запуск сохраняет его и проверяет, сжимает ли он каталог. При предупреждении о каталоге без gzip останови прежний API из его терминала или диспетчера процессов и повтори запуск. Рабочий адрес сайта и данные профиля в браузере сохраняются. [Режим разработки Uvicorn](https://github.com/Kludex/uvicorn/blob/main/docs/settings.md#development)

Исходники интерфейса лежат в `source/frontend/src`, рисунки в `source/frontend/public/art`, уроки и задачи в `source/backend/curriculum`. Для production-сборки запусти `corepack yarn build` из `source/frontend`. [Карта проекта](PROJECT.md) · [Журнал разработки](DEVELOPMENT.md)

Для доступа к прежнему прогрессу открывай сайт по тому же адресу `127.0.0.1:4184` и в том же профиле браузера. Для переноса есть скачивание и импорт файла в профиле Purradox. Таймер ЦТ отсчитывает время с начала попытки, в том числе пока страница закрыта.

Курс включает 49 тем, два варианта из банка тренажёра, два диагностических варианта с самостоятельными заданиями и короткое демо. Полные варианты содержат по 30 заданий и рассчитаны на 210 минут.
