# Работа над Purradox

Открой [AGENTS.md](../../../AGENTS.md) и [карту проекта](../../../PROJECT.md). Сверь корень Git, ветку и локальные изменения. Для двух разных копий проверяй затронутые файлы отдельно. Сверь рабочий сервер перед проверкой в браузере.

Найди строку карты по задаче. Для работы с уроком сначала определи тему, ID карточки и путь ученика до неё. Для дизайна открой ближайший принятый экран и подходящий референс из [DESIGN.md](../../../DESIGN.md). Для сохранений сверь формат старых данных и отмечай, какая именно попытка или вкладка пишет прогресс.

Выбирай проверку, способную обнаружить недостаток выбранного подхода. Если проверка выявила проблему с самой подачей задачи, пересмотри композицию или взаимодействие и повтори проверку на странице. Для снятия легаси найди его потребителей в маршрутах, импортах, ресурсах и тестах, сохрани материалы для восстановления и проверь затронутую границу сборки.

При передаче укажи рабочую копию, изменённые файлы или карточки, подтверждённый результат и открытые вопросы. Если изменилась точка входа, правило или состояние важного риска, обнови соответствующий документ из карты.
