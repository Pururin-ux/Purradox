# Purradox

Учебник и тренажёр по физике для подготовки к ЦТ. В курсе 49 тем, 298 задач, четыре пробных формы ЦТ и повторение ошибок.

## Локальный запуск

Понадобятся Node.js 22 с Corepack и Python 3.12. Следуй [инструкции по установке зависимостей](source/README.md). На Windows запусти из корня репозитория `start-local.cmd` и открой [Purradox](http://127.0.0.1:4184/).

Интерфейс и рисунки лежат в `source/frontend`, банк задач и API в `source/backend`. Прогресс хранится в браузере. Из профиля можно скачать файл для переноса на другое устройство.

Для production-сборки запусти `corepack yarn build` из `source/frontend`. Способ подключения API описан в [инструкции запуска](source/README.md). Проверки проекта запускаются в [GitHub Actions](.github/workflows/ci.yml).
